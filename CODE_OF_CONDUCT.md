# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, aceite críticas construtivas, foque no que é melhor
para a comunidade. Assédio e discriminação não são tolerados.

Para reportar uma violação, contate o mantenedor por
https://github.com/emersonSantos98 (mensagem privada) ou pelo reporte privado do repositório.
