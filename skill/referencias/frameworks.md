# Frameworks de copy [O/C]

Nenhum tem validação experimental comparativa robusta: são heurísticas de
ordenação. Escolha pelo nível de consciência e tipo de produto; registre a justificativa.

| Framework | Sequência | Quando | Efeito na estrutura |
|---|---|---|---|
| AIDA | Atenção → Interesse → Desejo → Ação | consciente do problema; genérico | hero → benefícios → prova → CTA |
| PAS | Problema → Agitação → Solução | dor forte; cursos, ferramentas | dor longa antes do produto |
| PAS + Why-Try-Buy | PAS + por que agora / tentar / comprar | página longa de curso | blocos de decisão após a solução |
| Before-After-Bridge | atual → desejado → ponte | transformação visível; mentoria, SaaS | hero de contraste; mecanismo é a ponte |
| 4Ps | Promise, Picture, Proof, Push | público morno; ticket médio | exige prova forte |
| PASTOR | Problem, Amplify, Story, Transformation, Offer, Response | lançamentos, cursos | página completa com stack |
| QUEST | Qualify, Understand, Educate, Stimulate, Transition | consciência baixa; B2B; categoria nova | qualificação cedo; educação no meio |
| Star-Story-Solution | personagem → história → solução | história real do especialista | abre com narrativa (só se verdadeira) |
| FAB | Feature → Benefit → Proof | consciente do produto; SaaS | grade de features com prova |
| Mecanismo único | nomeia por que funciona diferente | sofisticação 3–5 | mecanismo antes dos benefícios |
| Big Idea | ideia central que organiza tudo | páginas longas, VSL | headline, VSL e mecanismo giram nela |
| Jornada do Herói | chamado → provação → transformação | marca, especialista, comunidade | cliente é o herói; especialista, o mentor |
| PLF (lançamento) | PPL → CPLs → carrinho aberto | audiência construída | educação fora da página |

## Ferramentas de avaliação
- **4Us** (headline): Useful, Urgent, Unique, Ultra-specific — pontue 1–4 cada.
- **Teste de 5 segundos**: o que é, para quem, resultado, próximo passo.
- **Value Equation**: ver `oferta.md`.

## Escolha rápida
- inconsciente → Star-Story-Solution / Big Idea / QUEST
- problema → PAS / PASTOR
- solução → Before-After-Bridge / Mecanismo único / 4Ps
- produto → FAB / 4Ps
- muito consciente → oferta direta (AIDA curto)
