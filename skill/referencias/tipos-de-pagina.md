# Tipos de produto e página

| Tipo | Ordem recomendada | CTA | VSL | Prova | Preço | Objeções principais | Extensão |
|---|---|---|---|---|---|---|---|
| Infoproduto (e-book, template) | hero → dor → promessa → o que vem → prova → oferta+preço → garantia → FAQ | comprar | opcional | depoimentos curtos, prints reais | visível, à vista + parcelado | "vale?", "vou usar?" | curta–média |
| Curso online | hero/VSL → dor → mecanismo → transformação → módulos → professor → depoimentos → oferta+bônus → garantia → FAQ | comprar / lista de espera | comum no BR (tráfego frio) | vídeos de alunos, resultados específicos | âncora honesta + parcelamento | "já tentei", "sem tempo", "serve p/ iniciante?" | longa |
| Mentoria (ticket alto) | hero → para quem é/não é → transformação → método → mentor → cases → como funciona → investimento → FAQ | aplicação / call / WhatsApp | comum | cases com números | faixa ou após call | "vale?", "tenho perfil?" | longa |
| Comunidade | hero → isolamento → como é por dentro → quem participa → ganhos → preço recorrente → cancelamento → FAQ | assinar / lista de espera | opcional | nº real de membros, depoimentos | mensal/anual | "é ativa?", "posso sair?" | média |
| SaaS (PME) | hero+demo → logos → job → features como benefícios → integrações → depoimentos → pricing → FAQ | trial / freemium | raro | logos, uso, reviews | página de planos | integração, setup, custo ao crescer | média |
| SaaS B2B | hero → logos → ROI → casos por função → segurança → integrações → cases → planos (enterprise = vendas) | demo / vendas | não | logos, cases com métricas | "custom"/"a partir de" | segurança, migração, aprovação interna | média–longa |
| Ferramenta self-service | hero com a ferramenta → 3 passos → exemplos → preço → FAQ | usar grátis / comprar | não | contadores reais | simples | "serve pro meu caso?" | curta |
| Assinatura | hero → o que chega a cada ciclo → exemplos → preço → cancelamento → FAQ | assinar | opcional | reviews, nº de assinantes | mensal × anual com economia real | "posso cancelar?" | curta–média |
| Serviço digital | hero → resultado → processo → portfólio → pacotes → quem faz → FAQ | call / orçamento / WhatsApp | opcional | cases, portfólio | pacotes / "a partir de" | entrega, prazo | média |
| Ticket baixo | hero → o que é → prova rápida → preço → garantia | comprar | não | volume, avaliações | visível e cedo | "é confiável?" | curta |
| Ticket alto | educação → qualificação → prova profunda → contato humano | aplicação / call | comum | cases em vídeo | após diagnóstico ou faixa | risco, perfil, retorno | longa |

## Lançamento × perpétuo
- **Lançamento (PLF)**: a educação acontece fora da página (CPLs). A página de
  carrinho aberto é curta–média, centrada em oferta, prazo real e garantia.
- **Perpétuo com tráfego frio**: a página (ou VSL) faz toda a educação.

## Padrões observados em páginas de SaaS (Basecamp, Linear, Notion, Calendly, RD Station, Conta Azul — out/2026)
1. Headline de categoria + diferencial (público consciente da solução).
2. CTA de baixo risco ("grátis", "trial", "sem cartão") + rota para vendas no topo.
3. Plano recomendado destacado.
4. Toggle anual com economia explícita.
5. Prova numérica específica + logos de pares.
6. FAQ focado em cobrança, cancelamento, pagamento.
7. Enterprise "custom"/"a partir de"; self-service nunca esconde preço.
